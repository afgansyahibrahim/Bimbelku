PATCH CEPAT KELAS MURAH PRE-PAYMENT

1. Extract ZIP ini ke:
   C:\laragon\www\Website_Bimbelku
   pilih Replace/Overwrite bila diminta.

2. Terminal backend:
   cd C:\laragon\www\Website_Bimbelku\bimbelku-backend
   php artisan optimize:clear

3. Buat demo dari sebelum pembayaran:
   php artisan demo:cheap-class reset
   php artisan demo:cheap-class pre-payment

4. Login murid:
   demo.student@bimbelku.local / password
   buka Kelas Murah -> Gabung Kelas Murah -> tampilkan Payment.

5. Shortcut bila tidak mau upload bukti manual:
   php artisan demo:cheap-class payment-submitted

6. Admin bisa approve di UI. Fallback:
   php artisan demo:cheap-class payment-paid

7. Jadikan sesi live:
   php artisan demo:cheap-class session-live

8. Akhiri sesi:
   php artisan demo:cheap-class session-ended
