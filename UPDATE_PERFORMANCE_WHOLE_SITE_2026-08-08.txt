BIMBELKU - PERFORMANCE WHOLE-SITE REVISION
Tanggal: 8 Agustus 2026

Fokus:
- Mobile terlebih dahulu, Desktop tetap dijaga.
- Seluruh route/layout, bukan hanya /student/my-classes.
- Tidak mengubah desain, fitur, role, authorization, business logic, atau API contract.

Perubahan utama:
1. Current-route early preload untuk mengurangi waterfall lazy route.
2. Static Sonner imports turun dari 54 menjadi 1; toast dimuat saat benar-benar digunakan.
3. Landing below-fold section benar-benar deferred berdasarkan viewport.
4. Login/Forgot/Reset tidak memuat Axios sebelum submit.
5. Register mendefer CameraCapture dan SubjectCombobox teacher-only.
6. Student/Teacher layout tidak membiarkan request non-kritis berebut critical page fetch.
7. Student/Teacher MobileBottomNav tidak dimount di Desktop.
8. Tutorial global dijadwalkan non-kritis, fallback tutorial tetap tersedia.
9. MyClasses, ManageClasses, Search: critical hero tidak lagi menunggu data API.
10. LearningSessionHub/CameraCapture interaction-only dilazy-load.
11. Class list menggunakan content-visibility untuk card di luar viewport.
12. /student/classes dan /teacher/classes menggunakan cache/in-flight dedupe GET singkat.
13. /teacher/classes backend: unread count N+1 diganti withCount.
14. /student/classes backend: latest progress memakai latestOfMany, tidak memuat semua report lalu unique di PHP.
15. Dashboard teacher/admin menggunakan cache singkat; refresh manual tetap force network.
