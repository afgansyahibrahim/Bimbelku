# BimbelKu API

Backend Laravel untuk alur BimbelKu terbaru.

Petunjuk instalasi, aturan bisnis, konfigurasi scheduler, keamanan berkas, dan proses pembayaran manual tersedia pada [`../README.md`](../README.md).

API wajib dijalankan bersama MySQL dan Laravel Scheduler. Rekening admin, tarif per jam, komisi, batas kelompok, dan katalog materi harus dikonfigurasi dari panel admin sebelum layanan digunakan.
